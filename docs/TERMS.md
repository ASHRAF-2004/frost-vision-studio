2. Hardware scope
This release targets the 480 × 480 Invasion Frost Vision display with USB ID
345f:9132. It controls display content; it does not regulate the cooler pump,
fans, thermal protection or firmware. Other screens and resolutions are not
supported by this release. Only start output to hardware you own or administer.

4. Installation and drivers
The Windows installer installs Frost Vision Studio for the current user and
provides an uninstaller. It does not install the original manufacturer app,
silently replace USB drivers, or enable login startup without your choice.
Compatible USB access must already be available or be configured separately.
Uninstalling the application preserves your local composition settings and media.
